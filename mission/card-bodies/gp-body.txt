PLAN GATE — lane <N>. The driver never commits. Nothing is committed unless a human chooses to commit it.

The driver completes this card only when the newest plan-review verdict is PASS, and records the evidence (staged file count + verdict) in the result.

If this lane runs with human gates (the default), the driver pauses here and logs HUMAN GATE READY. Your options as the gate-holder:
1. Read <PLAN> and the newest plan-review verdict — the RVp card, or its latest re-review round — including its NOTES and any gap the plan card reported.
2. Inspect what is staged: git diff --cached --stat
3. Commit the plan if you want it in history — entirely at your discretion, with an explicit pathspec. The flow does not require it.
4. Complete this card. Write PASS — the driver adds its own evidence line beside it, so
   nothing else needs to be written:
       hermes kanban --board <BOARD> complete <YOUR-CARD-ID> --result "PASS: accepted"
   PASS is the first word and the only one that releases the lane; your own words may
   follow the colon ("PASS: plan is right, shipping it").

Complete it from the CLI (the command above), or from a browser on the dashboard — in a
browser the Complete dialog asks for a summary: type PASS (or PASS: <your words>) into it.
The desktop app cannot complete a card at all: its `Complete` collects the summary with
`window.prompt`, which Electron does not implement, so the click does nothing
(DESIGN.md, *Known traps*).

OPTIONAL: the board does not need it — the driver records the evidence line. MANDATORY in the dashboard's Complete dialog, so type PASS there.

Completing this card is what unblocks the lane's TW card. Never open the gate without a PASS verdict on record.
